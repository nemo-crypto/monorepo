# 替换范围与历史边界

本次按要求移除了工作目录中旧 packages 下的全部内容，包括实验、原生桥接、UI 组件、多语言资源和翻译工具。同时移除旧 src 业务模块、build 翻译脚本、Lerna 配置与过时教程，避免它们继续被构建或作为示例引用。

新建的 apps/planner、apps/report、packages/types、packages/utils、packages/learning 及其测试、配置和文档均围绕虚构课程示例独立编写。没有把旧业务实现搬到 legacy、压缩包或备份目录。旧接口不再兼容，依赖旧包的外部项目需要单独迁移。

**本次替换只涉及当前工作目录。** `.git`、历史提交、分支、标签及远程仓库没有被删除、改写或推送。因此不能把这个现有 Git 仓库描述为“历史已无旧代码”。

若后续需要对外分享全新的教学项目，应使用仅含新文件且不带旧 `.git` 的目录初始化新仓库，再检查分享范围。已有远程历史的处置属于单独操作，本次没有执行。
